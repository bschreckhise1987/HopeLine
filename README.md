ABOUT HOPELINE
--------------------------------------------------
HopeLine is a faith-centered recovery and support application designed to provide users with tools, encouragement, and community resources that can support them throughout their recovery journey.

This README provides the information needed to install, access, and test the application.


INSTALLATION INSTRUCTIONS
--------------------------------------------------
1. Open the HopeLine project in Xcode.

2. Allow Xcode to finish loading the project and resolving any required dependencies.

3. Select an available iOS Simulator or a compatible physical iOS device as the run destination.

4. Build and run the application using the Run button in Xcode.

5. Once the application launches, the HopeLine login screen can be used to access the application with the test account provided below.

ACCESSING APPLICATION FEATURES
--------------------------------------------------
After signing in with the test account, the reviewer can access the available HopeLine features through the application's navigation.

An active internet connection is recommended because features that communicate with the application's backend require network access.

If prompted for device permissions while testing a feature, please allow the requested permission so the feature can be evaluated as intended.


SPECIAL REQUIREMENTS
--------------------------------------------------
- Xcode is required to build and run the project from source.
- A compatible iOS Simulator or physical iOS device is required.
- An internet connection may be required for features that retrieve or save online data.
- Use the provided test account to access authenticated features.
- No account creation is necessary when using the provided test credentials.


TROUBLESHOOTING
--------------------------------------------------
If the application does not build immediately after opening the project:

1. Allow Xcode to finish resolving project dependencies.
2. Confirm that a compatible iOS Simulator or physical device is selected.
3. Clean and rebuild the project if necessary.
4. Confirm that the computer or device has an active internet connection.

If login is unsuccessful, verify that the test credentials have been entered exactly as shown in this README.
